# Git — fluxo de trabalho e recuperação

<toc-table />

## Objetivo

Praticar um fluxo completo de versionamento: criar repositório, registrar
commits, consultar histórico, restaurar mudanças, trabalhar com remoto e
resolver conflitos.

## Guide

Realize as etapas em pequenos commits e registre em um relatório o comando
executado, o estado observado e a decisão tomada. O objetivo não é decorar
comandos, mas compreender que commits são pontos de recuperação e que conflitos
exigem integração consciente.

## Verificação

Entregue o repositório de prática e um relatório curto com evidências de cada
etapa, incluindo um conflito resolvido.
